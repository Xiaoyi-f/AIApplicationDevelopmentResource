## 如何添加新文章

1. **命名**：新文件加序号前缀，格式为 `阶段号-序号 标题.md`，接在对应阶段末尾。
   - 例如阶段 5 再写一篇：`05-07 新文章标题.md`
   - 阶段号对照：`0` 建号 / `1` Python / `2` 后端 / `3` 数据库 / `4` AI 理论 / `5` AI 应用 / `6` 工程化 / `7` 实战 / `8` 走向国际
2. **登记**：在本文档对应阶段区块下，加一行链接：
   `- [05-07 新文章标题](<05-07 新文章标题.md>)`
3. **更新状态**：把上方「路线一览」表格里该阶段的「教程状态」数字 +1。
