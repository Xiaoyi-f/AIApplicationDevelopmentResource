## 一、基本位运算

| 运算符 | 名称 | 例子 | 结果 |
| --- | --- | --- | --- |
| `&` | 与 | `5 & 3` = `101 & 011` | `001` = 1 |
| `\|` | 或 | `5 \| 3` = `101 \| 011` | `111` = 7 |
| `^` | 异或 | `5 ^ 3` = `101 ^ 011` | `110` = 6 |
| `~` | 取反 | `~5` | 补码取反 |
| `<<` | 左移 | `1 << 3` | 8（乘 2³） |
| `>>` | 右移 | `8 >> 2` | 2（除 2²） |

**关键记忆**：
- `1 << k` 得到一个「第 k 位是 1」的数；
- `n << 1` 等于 `n * 2`，`n >> 1` 等于 `n // 2`；
- 异或 `^`：相同为 0，不同为 1。

> 一句话：**位运算直接操作二进制位，`<<`/`>>` 是乘除 2 的倍数，`^` 是「相同得 0、不同得 1」。**

## 二、lowbit 与位技巧

`lowbit(x) = x & (-x)`，取出 x 二进制里**最低位的 1 对应的值**。它在树状数组里已经见过，还有很多妙用：

```python
def lowbit(x):
    return x & (-x)

print(lowbit(12))  # 12=1100, 最低位1代表4 -> 4
```

**几个高频位技巧**（背下来）：

```python
# 判断奇偶
def is_odd(x):
    return x & 1 == 1

# 判断 x 是否是 2 的幂 (只有一个 1)
def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

# 把 x 最低位的 1 清零
def clear_lowest(x):
    return x & (x - 1)

# 统计 x 二进制里 1 的个数
def count_ones(x):
    return bin(x).count("1")
    # 或 Python 3.10+ 用 x.bit_count()

# 交换两个数 (不用临时变量)
def swap(a, b):
    a ^= b
    b ^= a
    a ^= b
    return a, b
```

```python
if __name__ == "__main__":
    print(is_power_of_two(16))  # True
    print(is_power_of_two(18))  # False
    print(count_ones(13))       # 13=1101 -> 3
    print(swap(3, 5))           # (5, 3)
```

> 一句话：**`x & (x-1)` 能清零最低位 1，它是「判断 2 的幂」「统计 1 的个数」的基石。**

## 三、异或的妙用

异或 `^` 有三个神奇性质，让它成为「位运算之王」：

1. **自反性**：`a ^ a = 0`（自己和自己异或得 0）；
2. **交换律结合律**：`a ^ b ^ a = b`（成对出现互相抵消）；
3. **恒等性**：`a ^ 0 = a`。

**经典题 1：只出现一次的数字**（数组中只有一个数出现一次，其余都出现两次）：

```python
def single_number(nums):
    res = 0
    for x in nums:
        res ^= x  # 成对的数互相抵消, 剩下的就是只出现一次的数
    return res

if __name__ == "__main__":
    print(single_number([4, 1, 2, 1, 2]))  # 4
```

**经典题 2：交换两个数**（不借助临时变量，见上面 `swap`）。

> 一句话：**异或的自反性「a ^ a = 0」让成对的数互相抵消，是「找只出现一次的数」的核心。**

## 四、子集枚举与状压

状态压缩（状压 DP）用**一个整数的二进制位表示「选/不选」**，第 i 位为 1 表示选中第 i 个元素。这样就能用整数高效枚举集合。

**枚举一个集合的所有子集**：

```python
def enumerate_subsets(mask):
    # 枚举 mask 的所有子集 (含空集)
    sub = mask
    res = []
    while True:
        res.append(sub)
        if sub == 0:
            break
        sub = (sub - 1) & mask  # 关键: 下一个子集
    return res

if __name__ == "__main__":
    # mask = 1011, 枚举所有子集
    print([bin(s) for s in enumerate_subsets(0b1011)])
    # ['0b1011', '0b1010', '0b1001', '0b1000', '0b11', '0b10', '0b1', '0b0']
```

**关键公式**：`sub = (sub - 1) & mask` 是枚举子集的核心，能无遗漏、无重复地遍历所有子集。

**枚举 n 个元素的所有组合（每个选/不选）**：

```python
def all_subsets(n):
    res = []
    for mask in range(1 << n):  # 0 ~ 2^n - 1
        subset = [i for i in range(n) if mask & (1 << i)]
        res.append(subset)
    return res

if __name__ == "__main__":
    print(all_subsets(3))
    # [[], [0], [1], [0,1], [2], [0,2], [1,2], [0,1,2]]
```

**常用位操作封装**（状压 DP 里高频）：

```python
mask | (1 << i)     # 把第 i 位设为 1 (加入元素 i)
mask & ~(1 << i)    # 把第 i 位清零 (移除元素 i)
mask & (1 << i)     # 判断第 i 位是否为 1
mask & (-mask)      # 取最低位的 1
```

> 一句话：**状压 = 用二进制位表示集合，`1<<i` 表示第 i 个元素，配合位运算高效枚举子集、状态转移。**

## 五、速查表

| 点 | 要点 |
| --- | --- |
| `1 << k` | 第 k 位为 1 的数 |
| `<<` / `>>` | 乘 / 除 2 的幂 |
| `^` | 相同得 0，不同得 1 |
| lowbit | `x & (-x)`，最低位 1 |
| 清零最低位 | `x & (x - 1)` |
| 判断 2 的幂 | `x & (x - 1) == 0` |
| 异或妙用 | 成对抵消，找只出现一次 |
| 子集枚举 | `sub = (sub - 1) & mask` |
| 状压 | 二进制位表示集合 |
