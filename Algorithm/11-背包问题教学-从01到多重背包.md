## 一、背包是什么

**背包问题**：在容量有限的容器里挑选物品，在约束条件下拿到最优价值的一类动态规划模型。

- 物品有两个核心属性：**占用体积 v、价值 w**。
- 核心约束：**总体积不能超过背包容量 m**。

**⚠️ 一个必须先纠正的误区**：
> 背包本质是 **DP**（状态转移枚举选或不选），**不是贪心**！贪心只在物品满足特定条件时才生效，绝大多数背包贪心得不到正确答案。

## 二、01 背包（每件选一次）

**定义**：每件物品只能选 0 次或 1 次。

```python
def zero_one_knapsack(n, m, goods):
    # dp[j]：容量j是否可达（能不能凑出这个体积）
    dp = [False] * (m + 1)
    # value[j]：凑出体积j时，可以获得的最大价值
    value = [0] * (m + 1)
    dp[0] = True  # 体积0，价值0，初始可达

    for v, w in goods:
        # 01背包：容量从大往小倒着遍历，避免同一个物品重复被选取
        for j in range(m, v - 1, -1):
            if dp[j - v]:
                dp[j] = True
                if value[j - v] + w > value[j]:
                    value[j] = value[j - v] + w
    return dp, value

if __name__ == "__main__":
    n = 3
    m = 8
    # (体积v,价值w)
    goods = [
        (3, 5),
        (4, 6),
        (5, 7)
    ]
    dp_arr, val_arr = zero_one_knapsack(n, m, goods)
    print("可达数组dp：", dp_arr)
    print("对应最大价值value：", val_arr)
```

**核心理解**：
- `dp[j]` 表示「容量 j 是否可达」，`value[j]` 表示「凑出容量 j 的最大价值」。
- **01 背包一维数组要倒序遍历**（`range(m, v-1, -1)`），因为每件物品只能用一次，倒序能避免「用自己更新自己」。

## 三、完全背包（每件无限选）

**定义**：每件物品可以选无限次。

```python
def complete_knapsack(n, m, goods):
    dp = [False] * (m + 1)
    value = [0] * (m + 1)
    dp[0] = True

    for v, w in goods:
        # 完全背包：容量从小到大正序遍历
        for j in range(v, m + 1):
            if dp[j - v]:
                dp[j] = True
                if value[j - v] + w > value[j]:
                    value[j] = value[j - v] + w
    return dp, value

if __name__ == "__main__":
    n = 3
    m = 8
    goods = [
        (3, 5),
        (4, 6),
        (5, 7)
    ]
    dp_arr, val_arr = complete_knapsack(n, m, goods)
    print("可达数组dp：", dp_arr)
    print("对应最大价值value：", val_arr)
```

**核心理解**：
- 和 01 背包唯一的区别就是**遍历顺序**：完全背包**正序遍历**（`range(v, m+1)`）。
- 正序遍历允许「用更新后的自己继续更新自己」，等价于「可以选多次」。

## 四、多重背包（每件限 c 次）

**定义**：每件物品最多选 c 次。

**核心技巧**：二进制拆分组装，把 c 个物品拆成 log(c) 组，每组当成一个独立的 01 背包，降低复杂度。

```python
def multiple_knapsack(n, m, goods):
    dp = [0] * (m + 1)

    for v, w, c in goods:
        k = 1
        while k <= c:
            # 拆出一组：k个打包在一起，体积v*k，价值w*k
            pack_v = v * k
            pack_w = w * k
            # 01背包倒序
            for j in range(m, pack_v - 1, -1):
                dp[j] = max(dp[j], dp[j - pack_v] + pack_w)
            c -= k
            k <<= 1  # k *= 2

        # 剩下不足2的幂的余数部分，单独一组
        if c > 0:
            pack_v = v * c
            pack_w = w * c
            for j in range(m, pack_v - 1, -1):
                dp[j] = max(dp[j], dp[j - pack_v] + pack_w)
    return dp

if __name__ == "__main__":
    n = 2
    m = 10
    # (体积v,价值w,数量c)
    goods = [
        (2, 3, 4),
        (3, 5, 2)
    ]
    dp_res = multiple_knapsack(n, m, goods)
    print(dp_res)
```

**核心理解（易错）**：
- **二进制拆分**：把「最多选 c 个」拆成「1 个、2 个、4 个、8 个…… + 余数」这些组，每组当独立物品做 01 背包。
- 例如 c=4 → 拆成 1 + 2 + 1（余数），`k` 每次翻倍（`k <<= 1`）。
- 最后剩下不足 2 的幂的余数（`c > 0`），单独打包一组。

## 五、一维遍历顺序（核心考点）

这是背包最经典、最容易答错的面试题：

| 背包类型 | 遍历顺序 | 原因 |
| --- | --- | --- |
| **01 背包** | 倒序（大→小） | 每件只能用一次，避免「自己更新自己」 |
| **完全背包** | 正序（小→大） | 每件可用无限次，允许「自己更新自己」 |
| **多重背包** | 拆分后倒序 | 拆成 01 背包，所以倒序 |

> 记忆口诀：**01 倒着来（只能用一次），完全正着来（能无限用）。**

## 六、三种背包速查表

| 类型 | 每件次数 | 遍历 | 关键 |
| --- | --- | --- | --- |
| 01 背包 | 0 或 1 | 倒序 | 基础模型 |
| 完全背包 | 无限 | 正序 | 正序允许复用 |
| 多重背包 | ≤ c | 二进制拆分 + 倒序 | 拆 log(c) 组转 01 |

---

**一句话总结**：背包 = **容量约束下选物品的 DP**。核心是「一维遍历顺序」——**01 倒序、完全正序、多重拆成 01**。记住这一条，背包题基本不慌。
