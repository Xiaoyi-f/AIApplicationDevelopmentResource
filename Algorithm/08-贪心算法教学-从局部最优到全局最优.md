## 一、贪心是什么

**贪心 = 每一步都选「当前看起来最好」的结果，期望最终得到全局最优。**

就像「爬台阶时每一步都选最高的那级」，但**不一定能到最高点**——这就是贪心的风险。

```
贪心：每步选局部最优 → 期望拼出全局最优
```

> 核心心法：**贪心不是「随便选」，而是「每步选当前最优」，但要能证明这样选最终是对的。**

---

## 二、贪心什么时候有效（重点）

**贪心不是万能的，很多情况下会失效。** 判断贪心是否可行的方法：**尝试找反例**。

- 如果找到一个反例（局部最优没有导致全局最优），说明贪心无效，得换 DP。
- 如果找不到反例，且能证明「局部最优不会让全局更差」，才能用贪心。

**一个常见的过度工程化陷阱（新手必读）**：
> 贪心思路下，如果你发现代码越写越复杂、条件越来越多，**很可能解题方向本身就错了**。好的贪心通常「极简」，如果写着写着变得「过度工程化」，及时回头重新想。

---

## 三、反悔贪心

**反悔贪心 = 先选，后面发现选错了还能「反悔」调整。**

普通贪心「选了就定了」，反悔贪心允许「撤销之前的选择」。这是贪心里的进阶技巧，遇到「选了还能改」的题时用。

## 四、题 1：盛最多水的容器（接雨水变体）

**题目**：给定高度数组，选两条线，和 x 轴围成的容器能装最多水。求最大面积。

**贪心思路**：双指针从两端向中间收，每次移动「较矮」的那边。

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        """解法一: 暴力解法（O(n²)，超时）"""
        # n = len(height)
        # cur_max = 0
        # for r in range(n - 1, -1, -1):
        #     right_height = height[r]
        #     for l in range(r):
        #         width = r - l
        #         left_height = height[l]
        #
        #         s = width * min(left_height, right_height)
        #
        #         if s > cur_max:
        #             cur_max = s
        #
        # return cur_max

        """解法二: 双指针（贪心，O(n)）"""
        n = len(height)
        left_x = 0
        right_x = n - 1
        cur_max = 0
        while left_x < right_x:
            s = (right_x - left_x) * min(height[left_x], height[right_x])

            if s > cur_max:
                cur_max = s

            if height[left_x] < height[right_x]:
                left_x += 1
            else:
                right_x -= 1

        return cur_max
```

**为什么贪心有效**：
- 面积 = 宽度 × 高度（取两边较矮者）。
- 宽度在缩小，想面积变大，只能让「较矮的边」变高。
- 所以**移动较矮的那边**，是唯一可能让面积变大的选择——这就是贪心。

> 一句话：**每次放弃「较矮的边」，因为留着它不可能让面积更大。**

## 五、题 2：通配符匹配

**题目**：`?` 匹配任意单个字符，`*` 匹配任意序列（含空），判断 `s` 能否被 `p` 匹配。

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        i = j = 0
        star_idx = -1
        s_tmp = 0
        while i < len(s):
            if j < len(p) and (p[j] == '?' or p[j] == s[i]):
                i += 1
                j += 1
            elif j < len(p) and p[j] == '*':
                star_idx = j
                s_tmp = i
                j += 1
            elif star_idx != -1:
                # 因为有*记录，当匹配失败可以回退到*的位置然后继续匹配
                # 有*匹配失败就多吞一个字符 -> 一个一个吞, 避免中间有忽略解
                j = star_idx + 1
                s_tmp += 1
                i = s_tmp
            else:
                return False
        while j < len(p) and p[j] == '*':
            j += 1
        return j == len(p)
```

**核心理解（易错）**：
- `star_idx` 记录最近一个 `*` 的位置，`s_tmp` 记录它当时「吞到 s 的哪里」。
- 匹配失败时，**回退到 `*`，让 `*` 多吞一个字符**，再继续匹配。这是贪心 + 回溯的关键。
- 「一个一个吞」很关键——`*` 每次只多吞一个字符，避免漏掉中间可能的解。

> 一句话：**`*` 先「空匹配」，失败了再「多吞一个字符」重试，这是贪心回溯的经典套路。**

## 六、题 3：无重叠区间

**题目**：给定若干区间，移除最少的区间，使剩下的区间互不重叠。返回需要移除的数量。

```python
from math import inf

class Solution:
    def eraseOverlapIntervals(self, intervals: list[list[int]]) -> int:
        """写法一：按右边界排序"""
        # if not intervals:
        #     return 0
        # intervals.sort(key=lambda x: x[1])
        # count = 1  # 记录不重叠区间的数量
        # end = intervals[0][1]
        # for i in range(1, len(intervals)):
        #     if intervals[i][0] >= end:
        #         count += 1
        #         end = intervals[i][1]
        # return len(intervals) - count

        """写法二：更简洁"""
        intervals.sort(key=lambda x: x[1])
        ans = 0
        pre_r = -inf
        for l, r in intervals:
            if l >= pre_r:
                ans += 1
                pre_r = r
        return len(intervals) - ans
```

**贪心策略**：
1. 按**右边界**升序排序（结束越早的区间，越「不挡路」）。
2. 依次选「左边界 ≥ 上一个右边界」的区间，这些就是能留下的最大不重叠集合。
3. 总区间数 − 留下的 = 需要移除的。

> 一句话：**贪心选「结束最早」的区间，给后面的区间留出最多空间。**

## 七、贪心速查表

| 点 | 要点 |
| --- | --- |
| 本质 | 每步选局部最优，期望拼出全局最优 |
| 什么时候用 | 找不到反例、能证明局部最优不损害全局 |
| 什么时候不能用 | 能举出反例（贪心失效，换 DP） |
| 判断方法 | 尝试找反例 |
| 反悔贪心 | 选错了还能撤销调整 |
| 警惕信号 | 代码越写越复杂 → 可能方向错了 |

---

**一句话总结**：贪心的核心是「**每步选当前最优，并且能证明这样不会错**」。先暴力找感觉，再想贪心；找到反例就果断换 DP，别死磕。
