## 二、八大阶段怎么走

### ① 总纲（01-02）——先看，别跳过
- 01 让你知道整条路长啥样，心里有数；
- 02 是你用 Python 打的**命根子**，快读快写、递归深度、PyPy 这些不会，后面题全白写。

### ② 地基（03）
- 数据结构是所有算法题的容器，九大结构搞懂，后面才能装得下。

### ③ 基础算法（04-09）——初赛主力得分区
- 排序、二分、前缀和、位运算、贪心、搜索，这六块是初赛 8 题里最容易拿分的，务必吃透。

### ④ 核心算法（10-13）——拉开差距的地方
- DP 是百度之星头号大考点，务必花最多时间；背包是 DP 的必考子集；数论和组合数学挑着学。

### ⑤ 高级数据结构（14-16）
- 字符串三件套、线段树/树状数组是官方点名考点，冲决赛必须会。

### ⑥ 图论（17-19）——第二大考点
- 最短路 + MST + 拓扑，图论题分值高、套路固定，性价比极高。

### ⑦ 几何（20）
- 初赛占比低，会叉积判方向、线段相交、凸包就够，可后置。

### ⑧ 工程拓展（21-24）
- 布隆过滤器、LRU、状态机、行为树偏工程应用，竞赛直接考得少，但能喂饱你的 AI 项目知识面，时间紧可跳过。

### ⑨ 实战（25）——最后一步
- 模板全会了，就要靠真题把「会模板」变成「会拿分」。这步不做，前面白学。

## 四、三条铁律

1. **先暴力，再优化**——题意没吃透别急着想最优解，先写暴力确认理解对；
2. **少交 WA**——ACM 赛制一次错误提交罚时 20 分钟，宁可本地多测也不乱交；
3. **用 PyPy 提交**——纯算法题 PyPy 比 CPython 快数倍，这是你用 Python 打国奖的关键加成。
