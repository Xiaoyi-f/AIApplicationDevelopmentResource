## 一、DP 的本质

**动态规划 = 把大问题拆成重叠的子问题，保存子问题答案避免重复计算，由子问题的最优解推出大问题的最优解。**

**两大核心（必背）**：

| 核心 | 含义 |
| --- | --- |
| **状态定义** | `dp[i]` 代表什么？（这一步想错全盘皆错） |
| **状态转移方程** | `dp[i]` 怎么由前面的状态推出？ |

> 一句话：**DP 的三步曲 = 定义状态 → 找转移方程 → 初始化 + 遍历求解。** 最难的是「定义状态」，状态定义对了，转移方程水到渠成。

---

## 二、DP 成立的两个前提

| 前提 | 含义 |
| --- | --- |
| **最优子结构** | 大问题的最优解由子问题的最优解组成 |
| **无后效性** | 状态只由它前面的状态推出，不会被后面的状态反向影响 |

> 两个前提都满足，才能用 DP。这是面试官最爱问的「为什么这题能用 DP」。

## 三、题 1：最长递增子序列（LIS）

**题目**：求数组里最长的「严格递增」子序列长度（子序列不要求连续）。

```python
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n  # 每个元素自身长度至少为1
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
        return max(dp)

if __name__ == "__main__":
    sol = Solution()
    print(sol.lengthOfLIS([10,9,2,5,3,7,101,18]))
```

**状态定义**：`dp[i]` = 以第 i 个元素结尾的最长上升子序列长度。

**状态转移**：`nums[j] < nums[i]` 时，`dp[i] = max(dp[i], dp[j]+1)`（j 在 i 前面）。

**⚠️ 易错点**：
- **子序列不要求连续；子数组要求连续**，别搞混。
- 优化：O(n²) 朴素版好理解，还有二分优化 O(nlogn) 版本。

## 四、题 2：爬楼梯

**题目**：爬 n 阶楼梯，每次爬 1 或 2 阶，有多少种方法。

```python
def climbStairs(n: int) -> int:
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

if __name__ == "__main__":
    print(climbStairs(5))  # 输出8
```

**状态定义**：`dp[i]` = 爬到第 i 阶的方案总数。

**状态转移**：`dp[i] = dp[i-1] + dp[i-2]`（到 i 阶，只能从 i-1 走 1 步，或 i-2 走 2 步）。

> 这就是斐波那契模型。还可以**空间优化**：只用两个变量，不用整个数组。

## 五、题 3：最长回文子序列

**题目**：求字符串里最长回文子序列的长度（子序列不连续）。

```python
def longestPalindromeSubseq(s: str) -> int:
    n = len(s)
    dp = [[0]*n for _ in range(n)]
    # 单个字符回文长度为1
    for i in range(n):
        dp[i][i] = 1

    # length：区间长度
    for length in range(2, n+1):
        for l in range(n - length + 1):
            r = l + length - 1
            if s[l] == s[r]:
                dp[l][r] = dp[l+1][r-1] + 2
            else:
                dp[l][r] = max(dp[l+1][r], dp[l][r-1])
    return dp[0][n-1]

if __name__ == "__main__":
    print(longestPalindromeSubseq("bbbab"))  # 输出4
```

**状态定义**：`dp[l][r]` = 字符串 `s[l...r]` 区间内最长回文子序列长度。

**状态转移**：
- `s[l] == s[r]` → `dp[l][r] = dp[l+1][r-1] + 2`
- `s[l] != s[r]` → `dp[l][r] = max(dp[l+1][r], dp[l][r-1])`

**⚠️ 易错点**：
- 这是**区间 DP**，套路是「先枚举区间长度，从小到大，小区间推大区间」。
- 子序列不连续；和「最长回文子串（连续）」别混淆。

## 六、题 4：树形 DP（没有上司的舞会）

**题目**：公司是棵树结构，每个人有快乐值，父子不能同时参加宴会，求最大快乐值。

```python
import sys
sys.setrecursionlimit(1000000)

def dance():
    n = int(input())
    happy = [0]*(n+1)
    for i in range(1, n+1):
        happy[i] = int(input())
    # 建图，邻接表
    g = [[] for _ in range(n+1)]
    has_father = [False]*(n+1)
    for _ in range(n-1):
        son, fa = map(int, input().split())
        g[fa].append(son)
        has_father[son] = True
    # 找根（没有上司的总老板）
    root = 1
    for i in range(1, n+1):
        if not has_father[i]:
            root = i
            break

    dp = [[0]*2 for _ in range(n+1)]

    def dfs(u):
        dp[u][1] = happy[u]
        for v in g[u]:
            dfs(v)
            dp[u][1] += dp[v][0]
            dp[u][0] += max(dp[v][0], dp[v][1])
    dfs(root)
    return max(dp[root][0], dp[root][1])
```

**状态定义**：
- `dp[u][0]` = 以 u 为根的子树，u **不参加**的最大快乐值
- `dp[u][1]` = 以 u 为根的子树，u **参加**的最大快乐值

**状态转移**：
- u 选 → 所有子节点都不能选：`dp[u][1] += dp[v][0]`
- u 不选 → 子节点可选可不选，取 max：`dp[u][0] += max(dp[v][0], dp[v][1])`

> **树形 DP 套路**：DFS 后序遍历，先算所有儿子，再更新父节点。注意父子不能同时到场；这里是一般多叉树（二叉树只是特例）。

## 七、题 5：编辑距离

**题目**：把 word1 变成 word2，支持删除、插入、替换三种操作（各 +1），求最少操作次数。

```python
def minDistance(word1: str, word2: str) -> int:
    n = len(word1)
    m = len(word2)

    dp = [[0] * (m + 1) for _ in range(n + 1)]

    # 初始化：word1前i个变成空串，需要全部删除，i次
    for i in range(n + 1):
        dp[i][0] = i
    # 初始化：空串变成word2前j个，需要全部插入，j次
    for j in range(m + 1):
        dp[0][j] = j

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            # 方案1：删除word1[i-1]
            delete = dp[i - 1][j] + 1
            # 方案2：插入word2[j-1]
            insert = dp[i][j - 1] + 1
            # 方案3：替换/不动
            replace = dp[i - 1][j - 1]
            if word1[i - 1] != word2[j - 1]:
                replace += 1

            dp[i][j] = min(delete, insert, replace)
    return dp[n][m]

if __name__ == "__main__":
    print(minDistance("horse", "ros"))           # 输出3
    print(minDistance("intention", "execution")) # 输出5
```

**状态定义**：`dp[i][j]` = word1 的前 i 个字符变成 word2 的前 j 个字符的最少操作次数。

**状态转移**（三种操作取最小）：
- 删除：`dp[i-1][j] + 1`
- 插入：`dp[i][j-1] + 1`
- 替换：`dp[i-1][j-1] + (字符是否相等 ? 0 : 1)`

> 编辑距离是**经典双串 DP**，核心是把「三种操作」都列出来取 min。

## 八、DP 速查表

| 题 | DP 类型 | 状态定义 |
| --- | --- | --- |
| LIS | 线性 DP | dp[i] 以 i 结尾的长度 |
| 爬楼梯 | 线性 DP | dp[i] 到 i 的方案数 |
| 回文子序列 | 区间 DP | dp[l][r] 区间内长度 |
| 树形 DP | 树上 DP | dp[u][0/1] 选不选 |
| 编辑距离 | 双串 DP | dp[i][j] 前 i 变前 j |

**一句话总结**：DP 的万能三步 = **定义状态 → 找转移方程 → 初始化遍历**。核心难点在「定义状态」，练熟「线性 / 区间 / 树形 / 双串」四大类型，DP 题就稳了。
