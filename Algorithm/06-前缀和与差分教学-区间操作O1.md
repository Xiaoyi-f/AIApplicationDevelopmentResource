## 一、前缀和解决什么问题

前缀和专门解决**「多次查询区间和」**的问题：给你一个数组，问一堆 `[l, r]` 区间里元素的和是多少。

**朴素做法**：每次查询从 l 加到 r，O(n)。查询 q 次就是 O(nq)，q 和 n 都上万时直接超时。

**前缀和**：预处理 O(n)，之后每次查询 O(1)。

> 一句话：**前缀和 = 提前算好「从头到每个位置的累加和」，之后任意区间和用减法一步得出。**

## 二、一维前缀和

前缀和数组 `pre[i]` 表示**前 i 个元素的和**（`pre[0] = 0`）：

```python
def build_prefix(arr):
    # arr 下标从 1 开始更方便, 这里按 0 开始处理
    n = len(arr)
    pre = [0] * (n + 1)
    for i in range(n):
        pre[i + 1] = pre[i] + arr[i]
    return pre

def range_sum(pre, l, r):
    # 查询原数组 [l, r] 闭区间和, l r 从 0 开始
    return pre[r + 1] - pre[l]

if __name__ == "__main__":
    arr = [1, 3, 5, 7, 9]
    pre = build_prefix(arr)
    print(range_sum(pre, 1, 3))  # 3+5+7 = 15
```

**核心公式**（背下来）：

```
区间和 [l, r] = pre[r+1] - pre[l]     # l r 从 0 开始
区间和 [l, r] = pre[r] - pre[l-1]     # l r 从 1 开始
```

> 一句话：**区间和 = 两个前缀和相减。** 这就是前缀和「O(1) 查询」的本质。

## 三、二维前缀和

二维前缀和解决**「多次查询子矩阵和」**：给一个矩阵，问 `(x1,y1)` 到 `(x2,y2)` 围成的子矩形元素和是多少。

```python
def build_prefix_2d(a, n, m):
    # a 是 n 行 m 列的矩阵, 下标从 1 开始
    pre = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            pre[i][j] = (pre[i - 1][j] + pre[i][j - 1]
                         - pre[i - 1][j - 1] + a[i][j])
    return pre

def rect_sum(pre, x1, y1, x2, y2):
    # 查询子矩阵 [x1..x2][y1..y2] 的和
    return (pre[x2][y2] - pre[x1 - 1][y2]
            - pre[x2][y1 - 1] + pre[x1 - 1][y1 - 1])
```

**记忆方法（容斥）**：子矩阵和 = 大矩形 - 上边一条 - 左边一条 + 左上角补回来。

```
[x1..x2][y1..y2] = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]
```

> 一句话：**二维前缀和是「容斥」：大 - 上 - 左 + 左上，一次算出任意子矩阵和。**

## 四、差分：区间加减

差分是前缀和的**逆运算**，解决**「多次区间加减，最后问一次结果」**的问题：

- 给你一个数组，要做 q 次操作：每次让 `[l, r]` 区间都加上一个数 v；
- 最后问数组长什么样。

**朴素做法**：每次操作遍历 l 到 r，O(n) 每次。差分让它变成 O(1) 每次。

**核心思想**：维护一个**差分数组 `d`**，`d[i] = a[i] - a[i-1]`。要在 `[l, r]` 加 v，只需：

```
d[l] += v
d[r+1] -= v
```

最后对差分数组做一次**前缀和**，就还原出结果。

```python
def diff_add(d, l, r, v):
    # 在 [l, r] 区间都加 v, l r 从 1 开始
    d[l] += v
    d[r + 1] -= v

if __name__ == "__main__":
    n = 5
    a = [0] * (n + 2)   # 初始全 0, 多开一位防越界
    d = [0] * (n + 2)

    # 两次操作: [1,3] 加 2, [2,5] 加 1
    diff_add(d, 1, 3, 2)
    diff_add(d, 2, 5, 1)

    # 对差分数组求前缀和, 还原结果
    for i in range(1, n + 1):
        a[i] = a[i - 1] + d[i]
    print(a[1:n + 1])  # [2, 3, 3, 1, 1]
```

**为什么 O(1)**：`d[l] += v` 表示「从 l 开始，后面所有元素都会 +v」；`d[r+1] -= v` 表示「从 r+1 开始抵消掉」。一加一减，正好只影响 `[l, r]`。

> 一句话：**差分 = 区间加在两端打个标记，最后前缀和还原。** 把「区间修改」从 O(n) 变成 O(1)。

## 五、前缀和 vs 差分

这对「镜像技巧」要分清各自适用场景：

| 技巧 | 解决 | 操作类型 | 何时用 |
| --- | --- | --- | --- |
| **前缀和** | 多次**查询**区间和 | 静态、只查不改 | 先预处理，查询 O(1) |
| **差分** | 多次**修改**区间值 | 动态、只改不查 | 先打标记，最后还原 |

**进阶组合**：如果既要「区间加」又要「区间求和」，就要上**树状数组 / 线段树**（下一篇高级数据结构会讲）。

> 一句话：**前缀和管「查」，差分管「改」。要「边改边查」，就得用树状数组/线段树。**

## 六、速查表

| 点 | 要点 |
| --- | --- |
| 前缀和 | 预处理 O(n)，区间和 O(1) |
| 一维公式 | `[l,r] = pre[r+1] - pre[l]` |
| 二维公式 | 大 - 上 - 左 + 左上 |
| 差分 | 区间加只改两端 `d[l]+=v, d[r+1]-=v` |
| 差分还原 | 对差分数组求前缀和 |
| 前缀和 vs 差分 | 查用前缀和，改用差分 |
| 边改边查 | 用树状数组/线段树 |
