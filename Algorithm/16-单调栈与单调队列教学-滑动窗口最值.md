## 一、它们解决什么问题

很多题会陷入 O(n²) 的「暴力扫描」：

- 找每个元素「右边第一个比它大的」→ 暴力要两重循环；
- 求「每个长度为 k 的滑动窗口里的最大值」→ 暴力每个窗口扫一遍。

**单调栈 / 单调队列的思路**：维护一个「始终单调」的结构，把没用的元素及时踢掉，每个元素**最多进出一次**，于是整体 O(n)。

> 一句话：**单调结构 = 维护一个单调序列，边进边踢掉没用的，每个元素只进出一趟，复杂度 O(n)。**

## 二、单调栈：下一个更大元素

经典题：**「给你一个数组，求每个元素右边第一个比它大的元素」**（没有就是 -1）。

**单调栈的思路**：维护一个**栈底到栈顶递减**的栈（存下标）。从左往右遍历：

- 当前元素比栈顶大 → 说明当前元素就是栈顶的「下一个更大元素」，**弹栈顶**，记录答案；
- 一直弹到栈顶比当前大为止，再把当前元素入栈。

```python
def next_greater(arr):
    n = len(arr)
    res = [-1] * n
    stack = []  # 存下标, 栈内对应值递减
    for i, x in enumerate(arr):
        while stack and arr[stack[-1]] < x:
            # 栈顶元素的下一个更大元素就是 x
            res[stack.pop()] = x
        stack.append(i)
    return res

if __name__ == "__main__":
    print(next_greater([2, 1, 2, 4, 3]))
    # [4, 2, 4, -1, -1]
```

**为什么 O(n)**：每个元素最多**入栈一次、出栈一次**，虽然有两层循环，但总操作次数是 O(n)。

> 一句话：**单调栈维护「递减栈」，当前元素比栈顶大就弹栈记录答案，每个元素进出一次，O(n)。**

## 三、单调栈完整实现

单调栈还能解决一大类「边界」问题，比如**「柱状图中最大矩形」**、**「接雨水」**（你贪心篇已经见过接雨水）。核心都是「找左/右第一个更小/更大的位置」。

```python
# 求每个元素「左边第一个比它小的下标」和「右边第一个比它小的下标」
def nearest_smaller(arr):
    n = len(arr)
    left = [-1] * n   # 左边第一个更小
    right = [n] * n   # 右边第一个更小

    # 求右边第一个更小: 递增栈
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] > arr[i]:
            right[stack.pop()] = i
        stack.append(i)

    # 求左边第一个更小: 从左往右维护递增栈
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] >= arr[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)
    return left, right

if __name__ == "__main__":
    left, right = nearest_smaller([2, 1, 5, 6, 2, 3])
    print(left)   # [-1, -1, 1, 2, 1, 4]
    print(right)  # [1, 6, 4, 4, 6, 6]
```

**单调栈口诀**：
- 求「下一个**更大**」→ **递减栈**（栈顶小，遇到大就弹）；
- 求「下一个**更小**」→ **递增栈**（栈顶大，遇到小就弹）。

> 一句话：**找更大用递减栈，找更小用递增栈，方向反了就错了。**

## 四、单调队列：滑动窗口最值

经典题：**「给一个数组和窗口大小 k，求每个滑动窗口内的最大值」**。

**单调队列的思路**：维护一个**队头到队尾递减**的双端队列（存下标），队头始终是当前窗口的最大值：

1. 队头下标「滑出窗口」了 → 弹出队头；
2. 新元素比队尾大 → 弹出队尾（队尾没用了，因为新元素更大且更晚过期）；
3. 新元素入队尾；
4. 窗口成型后，队头就是窗口最大值。

```python
from collections import deque

def max_sliding_window(arr, k):
    n = len(arr)
    res = []
    dq = deque()  # 存下标, 队内对应值递减
    for i, x in enumerate(arr):
        # 1. 弹出滑出窗口的队头
        if dq and dq[0] <= i - k:
            dq.popleft()
        # 2. 弹出队尾所有比 x 小的 (它们没用了)
        while dq and arr[dq[-1]] <= x:
            dq.pop()
        # 3. 入队
        dq.append(i)
        # 4. 窗口成型后记录队头
        if i >= k - 1:
            res.append(arr[dq[0]])
    return res

if __name__ == "__main__":
    print(max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))
    # [3, 3, 5, 5, 6, 7]
```

**为什么队头是最大值**：队列始终递减，队头最大；队内每个元素都「比后面的大，且比后面的先过期」——所以队头既是最值，也是最先要检查过期的那一个。

> 一句话：**单调队列维护递减双端队列，队头即窗口最大值；弹过期、弹更小、入队、取队头四步走。**

## 五、单调队列完整实现

单调队列还能求**滑动窗口最小值**（把递减改成递增即可），以及「**限长序列求最值/最优**」类问题。

```python
from collections import deque

def min_sliding_window(arr, k):
    n = len(arr)
    res = []
    dq = deque()
    for i, x in enumerate(arr):
        if dq and dq[0] <= i - k:
            dq.popleft()
        while dq and arr[dq[-1]] >= x:  # 递增队列: 弹掉更大的
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            res.append(arr[dq[0]])
    return res

if __name__ == "__main__":
    print(min_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))
    # [-1, -3, -3, -3, 3, 3]
```

**单调栈 vs 单调队列对比**：

| 维度 | 单调栈 | 单调队列 |
| --- | --- | --- |
| 结构 | 栈（一端进出） | 双端队列（两端） |
| 维护 | 单调递增/递减栈 | 单调递增/递减队列 |
| 应用 | 下一个更大/更小元素、最大矩形 | 滑动窗口最值 |
| 复杂度 | O(n) | O(n) |

> 一句话：**单调栈管「找边界元素」，单调队列管「滑动窗口最值」，核心都是「单调 + 及时踢掉没用的」。**
