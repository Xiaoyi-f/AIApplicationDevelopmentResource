## 一、什么是拓扑排序

拓扑排序针对**有向无环图（DAG）**，把节点排成一个线性顺序，使得**每条边的起点都排在终点前面**。

```
课程依赖:  A → B → D
           ↘   ↗
             C
一个合法的拓扑序: A, C, B, D  (或 A, B, C, D)
```

**关键前提**：拓扑排序**只对 DAG 有效**。如果图里有环（A→B→C→A），就排不出合法顺序——这也正是「判环」的依据。

> 一句话：**拓扑排序 = 把「有依赖关系」的事排成一条合法的先后顺序，只在无环图里存在。**

## 二、Kahn 算法（入度法）

Kahn 算法是最经典的拓扑排序，核心思想是**「入度（指向它的边数）为 0 的节点，没有前置依赖，可以先做」**：

1. 统计每个节点的**入度**；
2. 把所有**入度为 0** 的节点放进队列；
3. 不断从队列取出节点，删掉它的所有出边（邻居入度 -1），若邻居入度变成 0 就入队；
4. 取出的节点顺序就是拓扑序。

```python
from collections import deque

def topo_sort(n, edges):
    # n 个节点编号 1~n, edges = [(u, v), ...] 表示 u -> v
    g = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    for u, v in edges:
        g[u].append(v)
        indeg[v] += 1

    q = deque([i for i in range(1, n + 1) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order
```

> 一句话：**Kahn 算法 = 入度为 0 就入队，出队就删出边，邻居入度减到 0 再入队。** 出队顺序就是拓扑序。

## 三、完整实现

```python
from collections import deque

def topo_sort(n, edges):
    g = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    for u, v in edges:
        g[u].append(v)
        indeg[v] += 1

    q = deque([i for i in range(1, n + 1) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    if len(order) < n:  # 有环, 排不满
        return None, True  # (无合法拓扑序, 有环)
    return order, False

if __name__ == "__main__":
    # 课程依赖: 1->2, 1->3, 2->4, 3->4
    order, has_cycle = topo_sort(4, [(1, 2), (1, 3), (2, 4), (3, 4)])
    print(order)      # 一个合法拓扑序, 如 [1, 3, 2, 4]
    print(has_cycle)  # False

    # 有环: 1->2, 2->3, 3->1
    order2, has_cycle2 = topo_sort(3, [(1, 2), (2, 3), (3, 1)])
    print(order2)       # None
    print(has_cycle2)   # True
```

**判环技巧就藏在最后**：如果拓扑排序输出的节点数 `len(order) < n`，说明有节点始终入度不为 0（成环了），排不出来。

## 四、有向图判环

有向图判环有三种主流方法，竞赛里**Kahn 拓扑法最常用**（顺便就把拓扑序求了）：

| 方法 | 思路 | 复杂度 |
| --- | --- | --- |
| **Kahn 拓扑法** | 拓扑序排不满就有环 | O(n+m) |
| **DFS 三色标记** | 访问中(灰)节点被再次遇到 = 环 | O(n+m) |
| **并查集** | 只适合无向图判环 | O(n) |

**DFS 三色标记法**（想要「找到具体环在哪」时用）：

```python
def has_cycle_dfs(n, edges):
    import sys
    g = [[] for _ in range(n + 1)]
    for u, v in edges:
        g[u].append(v)

    # 0=未访问, 1=访问中(在当前递归栈), 2=访问完
    color = [0] * (n + 1)
    sys.setrecursionlimit(10 ** 6)

    def dfs(u):
        color[u] = 1  # 标记访问中
        for v in g[u]:
            if color[v] == 1:   # 撞上正在访问的节点 = 环
                return True
            if color[v] == 0 and dfs(v):
                return True
        color[u] = 2  # 访问完
        return False

    for i in range(1, n + 1):
        if color[i] == 0 and dfs(i):
            return True
    return False
```

> 一句话：**判环首选 Kahn（排不满 = 有环）；要找具体环，用 DFS 三色标记。**
