## 一、组合数取模的难点

组合数公式：

```
C(n, k) = n! / (k! * (n-k)!)
```

直接算有两个坑：

1. **溢出**：n! 增长极快，n=100 就远超 Python 常规精度需求，更别说大 n；
2. **除法没法直接取模**：`(a / b) % mod` 不能拆成 `(a % mod) / (b % mod)`，因为除法在模运算下不能直接分配。

**解法**：把「除法」变成「乘逆元」，这样就能正常取模了。

> 一句话：**组合数取模的难点是「除法不能直接取模」，解决方法是「乘逆元」。**

---

## 二、乘法逆元

**逆元的定义**：在模 p 下，如果 `a * x ≡ 1 (mod p)`，那么 x 就是 a 的**乘法逆元**，记作 `a^(-1)`。

有了逆元，**除法就变成乘法**：

```
(a / b) % p = (a * b^(-1)) % p
```

这样就能安全取模了。

> 一句话：**逆元 = 「模意义下的倒数」，把除法变乘法，从而能对除法取模。**

---

## 三、费马小定理求逆元

**费马小定理**：当 p 是质数，且 a 不是 p 的倍数时：

```
a^(p-1) ≡ 1 (mod p)
```

由此推出：

```
a^(p-2) * a ≡ 1 (mod p)   =>   a^(-1) = a^(p-2) (mod p)
```

**所以：逆元 = 快速幂求 `a^(p-2)`。** 你数论篇学的快速幂，这里直接派上用场。

```python
MOD = 10 ** 9 + 7  # 竞赛常用质数模数

def qpow(a, b, mod):
    # 快速幂: a^b % mod
    res = 1
    while b:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res

def inv(a, mod=MOD):
    # 费马小定理求逆元: a^(mod-2)
    return qpow(a, mod - 2, mod)

if __name__ == "__main__":
    print(inv(3))        # 3 的逆元
    print(3 * inv(3) % MOD)  # 1, 验证
```

> 一句话：**模 p 为质数时，逆元 = `a^(p-2) mod p`，用快速幂算，O(log p)。**

## 四、组合数取模完整实现

有了逆元，组合数取模的标准做法是**预处理阶乘和阶乘的逆元**，之后每次查询 O(1)：

```python
MOD = 10 ** 9 + 7

def qpow(a, b, mod):
    res = 1
    while b:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res

def build_factorial(n, mod=MOD):
    # fact[i] = i!, inv_fact[i] = (i!)^-1
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % mod
    # 先算 n! 的逆元, 再倒推 (利用阶乘的递推关系)
    inv_fact[n] = qpow(fact[n], mod - 2, mod)
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % mod
    return fact, inv_fact

def C(n, k, fact, inv_fact, mod=MOD):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % mod * inv_fact[n - k] % mod

if __name__ == "__main__":
    N = 1000
    fact, inv_fact = build_factorial(N)
    print(C(10, 3, fact, inv_fact))  # 120
    print(C(100, 50, fact, inv_fact))  # 大组合数取模
```

**核心理解**：

| 步骤 | 说明 |
| --- | --- |
| 预处理 fact | `fact[i] = i! mod p`，O(n) |
| 预处理 inv_fact | 先求 `(n!)^-1`，再倒推 `(i-1)!^-1 = (i!)^-1 * i`，O(n) |
| 查询 | `C(n,k) = fact[n] * inv_fact[k] * inv_fact[n-k]`，O(1) |

**倒推阶乘逆元的妙处**：`(i-1)! = i! / i`，所以 `(i-1)!^-1 = i!^-1 * i`，一次快速幂算出 `n!` 的逆元后，其余全部 O(1) 倒推出来。

> 一句话：**预处理「阶乘 + 阶乘逆元」，组合数查询 O(1)；阶乘逆元用一次快速幂 + 倒推搞定。**

## 五、常用公式

竞赛计数题常用的组合恒等式，背下来：

| 公式 | 含义 |
| --- | --- |
| `C(n,k) = C(n, n-k)` | 对称性 |
| `C(n,k) = C(n-1,k) + C(n-1,k-1)` | 帕斯卡恒等式（杨辉三角） |
| `C(n,k) = C(n,k-1) * (n-k+1) / k` | 递推求组合数 |
| `sum C(n,i) = 2^n` | 所有子集数 |
| **二项式定理** | `(a+b)^n = Σ C(n,k) a^k b^(n-k)` |

**小 n 时用杨辉三角**（O(n²) 预处理，无需逆元）：

```python
def build_pascal(n):
    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = C[i][i] = 1
        for j in range(1, i):
            C[i][j] = (C[i - 1][j] + C[i - 1][j - 1]) % MOD
    return C
```

> 一句话：**n 小（≤ 5000）用杨辉三角，n 大且模为质数用「阶乘 + 逆元」。**
