## 一、点与向量

计算几何里，**点**和**向量**都可以用二元组 `(x, y)` 表示。向量 `AB = (B.x - A.x, B.y - A.y)`。

```python
# 用元组 (x, y) 表示点和向量
def vec(a, b):
    # 向量 a -> b
    return (b[0] - a[0], b[1] - a[1])
```

**避坑提醒**：几何题要**尽量用整数**，避免浮点误差。判断相等、比较时用「叉积/点积的符号」而非「浮点相减」。

> 一句话：**点 = (x, y)，向量 = 终点减起点。几何题优先用整数和「符号判断」规避浮点精度坑。**

## 二、叉积：判断方向与面积

叉积（cross product）是计算几何**最重要的运算**。二维叉积：

```
cross(a, b) = a.x * b.y - a.y * b.x
```

它的几何意义：`|cross|` 等于两向量张成的**平行四边形面积**，**符号**表示方向（顺时针/逆时针）。

```python
def cross(a, b):
    # 二维叉积: 返回标量
    return a[0] * b[1] - a[1] * b[0]

# 判断向量 a 到 b 是逆时针(正)还是顺时针(负)
# cross > 0: 逆时针 (a 在 b 的左边)
# cross < 0: 顺时针 (a 在 b 的右边)
# cross == 0: 共线
```

**核心应用 1：判断点 C 在向量 AB 的哪一侧**：

```python
def side(a, b, c):
    # 返回正: C 在 AB 左侧, 负: 右侧, 0: 共线
    return cross(vec(a, b), vec(a, c))

if __name__ == "__main__":
    a, b = (0, 0), (2, 0)
    print(side(a, b, (1, 1)))    # 正 -> 左侧 (上方)
    print(side(a, b, (1, -1)))   # 负 -> 右侧 (下方)
    print(side(a, b, (3, 0)))    # 0 -> 共线
```

**核心应用 2：三角形面积**：

```python
def area2(a, b, c):
    # 三角形有向面积的 2 倍 (可能为负)
    return cross(vec(a, b), vec(a, c))

# 三角形面积 = abs(area2) / 2
```

> 一句话：**叉积 = `a.x*b.y - a.y*b.x`，符号判方向、绝对值算面积，是计算几何的万金油。**

## 三、点积：判断角度

点积（dot product）用来判断**角度**：

```
dot(a, b) = a.x * b.x + a.y * b.y
```

| 点积符号 | 含义 |
| --- | --- |
| `> 0` | 夹角锐角 |
| `= 0` | 直角 |
| `< 0` | 钝角 |

```python
def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]
```

**典型应用**：判断「点在以线段为直径的圆内」，本质是判断角度是否为钝角。

> 一句话：**点积判角度（锐/直/钝），叉积判方向（顺/逆时针）。两者配合覆盖几何题大半。**

## 四、线段相交

判断两条线段 `AB` 和 `CD` 是否相交，是几何题的经典基础。核心是**「跨立实验」**：

两条线段相交，当且仅当 **A、B 分别在 CD 两侧**，且 **C、D 分别在 AB 两侧**（端点重合也视为相交）。

```python
def on_segment(a, b, p):
    # 判断 p 是否在线段 ab 上 (假设 p 与 a b 共线)
    return (min(a[0], b[0]) <= p[0] <= max(a[0], b[0]) and
            min(a[1], b[1]) <= p[1] <= max(a[1], b[1]))

def segments_intersect(a, b, c, d):
    d1 = side(c, d, a)
    d2 = side(c, d, b)
    d3 = side(a, b, c)
    d4 = side(a, b, d)

    # 一般情况: 严格跨立
    if ((d1 > 0 and d2 < 0) or (d1 < 0 and d2 > 0)) and \
       ((d3 > 0 and d4 < 0) or (d3 < 0 and d4 > 0)):
        return True
    # 边界情况: 端点在另一条线段上
    if d1 == 0 and on_segment(c, d, a):
        return True
    if d2 == 0 and on_segment(c, d, b):
        return True
    if d3 == 0 and on_segment(a, b, c):
        return True
    if d4 == 0 and on_segment(a, b, d):
        return True
    return False

if __name__ == "__main__":
    print(segments_intersect((0, 0), (2, 2), (0, 2), (2, 0)))  # True (十字相交)
    print(segments_intersect((0, 0), (1, 1), (2, 2), (3, 3)))  # False (共线但不重叠)
```

> 一句话：**线段相交 = 跨立实验：A、B 在 CD 两侧 且 C、D 在 AB 两侧，再处理端点重合的边界。**

## 五、点到线段距离

求点 P 到线段 AB 的最短距离，分三种情况（用点积判断垂足落在哪里）：

```python
import math

def dist_point_segment(p, a, b):
    ap = vec(a, p)
    ab = vec(a, b)
    t = dot(ap, ab) / (dot(ab, ab) or 1)  # 投影比例
    if t <= 0:
        # 垂足在 A 之外, 距离 = PA
        return math.hypot(ap[0], ap[1])
    if t >= 1:
        # 垂足在 B 之外, 距离 = PB
        bp = vec(b, p)
        return math.hypot(bp[0], bp[1])
    # 垂足在线段上
    proj = (a[0] + t * ab[0], a[1] + t * ab[1])
    return math.hypot(p[0] - proj[0], p[1] - proj[1])
```

> 一句话：**点到线段距离 = 用点积算投影比例，垂足在段内用垂线距离，段外取端点距离。**

## 六、多边形面积

任意多边形（顶点按顺序给出）的面积，用**叉积求和**：

```python
def polygon_area(points):
    # points: 按顺序排列的顶点列表 [(x,y), ...]
    n = len(points)
    s = 0
    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        s += x1 * y2 - x2 * y1  # 叉积累加
    return abs(s) / 2
```

**原理**：把多边形拆成一个个三角形（都连到原点），用叉积算每个三角形有向面积，累加后取绝对值。

> 一句话：**多边形面积 = 相邻顶点叉积累加取半，公式 `Σ (x1*y2 - x2*y1) / 2`。**

## 七、凸包

凸包是「**包住所有点的最小凸多边形**」，是计算几何的压轴。Andrew 算法（单调链法）最常用：

1. 按 (x, y) 排序；
2. 先求**下凸壳**（从左到右），再求**上凸壳**（从右到左）；
3. 维护一个栈，用叉积判断「新点是否让栈顶变凹」，凹了就弹栈。

```python
def convex_hull(points):
    pts = sorted(points)  # 按 (x, y) 排序去重
    pts = [pts[i] for i in range(len(pts))
           if i == 0 or pts[i] != pts[i - 1]]

    if len(pts) <= 2:
        return pts

    def cross_o(a, b, c):
        # 向量 ab 与 ac 的叉积
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

    # 下凸壳
    lower = []
    for p in pts:
        while len(lower) >= 2 and cross_o(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    # 上凸壳
    upper = []
    for p in reversed(pts):
        while len(upper) >= 2 and cross_o(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    # 去掉首尾重复点
    return lower[:-1] + upper[:-1]

if __name__ == "__main__":
    pts = [(0, 0), (1, 1), (2, 2), (3, 1), (2, 0), (1, -1)]
    print(convex_hull(pts))
    # [(0, 0), (2, 0), (3, 1), (2, 2), (1, -1)]
```

**核心判断**：`cross_o(栈顶前一个, 栈顶, 新点) <= 0` 说明「新点让路径右拐（变凹）」，弹出栈顶。维护「始终左拐」的路径，就是凸包。

> 一句话：**凸包 = 排序 + 单调栈 + 叉积判拐向。叉积 ≤ 0 弹栈，保持「一路左拐」。**
