## 一、排序要先搞懂的两个概念

| 概念 | 含义 | 一句话 |
| --- | --- | --- |
| **时间复杂度** | 随数据量增长，耗时怎么变 | 快不快 |
| **稳定性** | 相等元素的相对顺序会不会变 | 排序后相等的数还保持原顺序 |

**稳定性很重要吗？** 很重要。比如按「姓名」排好序，再按「成绩」排，如果是**稳定排序**，成绩相同的人姓名仍按字典序排。不稳定排序就会打乱。

## 二、快速排序（快排）

**思想**：选一个「基准值」（pivot），把小于它的放左边、大于它的放右边，然后递归处理左右两边。

```python
# 快速排序 nlogn
def quick_sort(arr, low, high):
    def partition(arr, low, high):
        pivot = arr[high]
        i = low - 1

        for j in range(low, high):
            if arr[j] <= pivot:
                i += 1
                arr[i], arr[j] = arr[j], arr[i]

        arr[i + 1], arr[high] = arr[high], arr[i + 1]

        return i + 1

    if low < high:
        p = partition(arr, low, high)
        quick_sort(arr, low, p - 1)
        quick_sort(arr, p + 1, high)

if __name__ == "__main__":
    nums = [5, 2, 9, 3, 7, 6, 1, 8]
    quick_sort(nums, 0, len(nums) - 1)
    print(nums)
```

**核心理解（易错）**：
- `partition` 是灵魂：把 `pivot` 放到「最终位置」，左边都 ≤ 它，右边都 > 它。
- `i` 记录「小于 pivot 的区域边界」，`j` 一路扫描，遇到小的就换到 `i` 这边。
- 快排**不稳定**（交换会打乱相等元素）。

## 三、归并排序

**思想**：分治——先递归把数组拆成单个元素，再两两合并成有序数组。

```python
# 归并排序 稳定 nlogn
def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    # 合并两个有序数组
    res = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i])
            i += 1
        else:
            res.append(right[j])
            j += 1

    res.extend(left[i:])
    res.extend(right[j:])

    return res

if __name__ == "__main__":
    nums = [5, 2, 9, 3, 7, 6, 1, 8]
    print(merge_sort(nums))
```

**核心理解（易错）**：
- 归并是**稳定的**：合并时 `left[i] <= right[j]` 用 `<=` 先取左边，保证相等元素的相对顺序。
- 需要额外 O(n) 空间存合并结果。

> 对比记忆：**快排 = 先分区后递归（原地，不稳定）；归并 = 先递归后合并（要额外空间，稳定）。**

## 四、堆排序

**思想**：先建「大顶堆」（堆顶是最大值），然后每次把堆顶（最大值）换到末尾，再调整剩下的堆。

```python
# 堆排序 大根堆 nlogn
def heap_sort(arr):
    def heapify(arr, n, i):
        largest = i
        l = 2 * i + 1
        r = 2 * i + 2

        if l < n and arr[l] > arr[largest]:
            largest = l

        if r < n and arr[r] > arr[largest]:
            largest = r

        if largest != i:
            arr[i], arr[largest] = arr[largest], arr[i]
            heapify(arr, n, largest)

    n = len(arr)

    # 建大顶堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # 依次把堆顶最大值放到末尾
    for i in range(n - 1, 0, -1):
        arr[i], arr[0] = arr[0], arr[i]
        heapify(arr, i, 0)

if __name__ == "__main__":
    nums = [5, 2, 9, 3, 7, 6, 1, 8]
    heap_sort(nums)
    print(nums)
```

**堆的下标规律（必背）**：

```python
n = len(arr)
# 下标从零开始, 左孩子 l = 2 * i + 1, 右孩子 r = 2 * i + 2
# 父节点: p = (i - 1) // 2
# 最后一个子根结点: n // 2 - 1
```

**核心理解（易错）**：
- `heapify(arr, n, i)`：从 `i` 往下「下沉」，让 `i` 这个子树重新满足大顶堆。
- **建堆**从 `n // 2 - 1`（最后一个非叶子节点）倒着往前调。
- **排序**：堆顶（最大值）和末尾交换，堆大小减一，再 `heapify` 下沉新堆顶。
- 堆排序**不稳定**。

## 五、其它 7 种排序速览

### ① 冒泡排序

- 思想：相邻元素比较交换，每一轮把最大值「冒泡」到末尾
- 时间：最好 O(n)（优化版），最坏/平均 O(n²)
- 空间：O(1)；**稳定**
- 评价：简单，数据量大完全不适合

### ② 直接插入排序

- 思想：分成有序区、无序区，依次拿无序区元素插入有序区合适位置
- 时间：最好 O(n)（已有序），最坏/平均 O(n²)
- 空间：O(1)；**稳定**
- 评价：小规模、接近有序的数据很好用

### ③ 简单选择排序

- 思想：每一轮在无序区找最小值，和无序区首位置交换
- 时间：始终 O(n²)
- 空间：O(1)；**不稳定**（交换打乱相等元素相对位置）

### ④ 希尔排序（缩小增量排序）

- 思想：插入排序的优化，按增量分组做插入排序，增量逐步缩小到 1
- 时间：介于 O(n²) ~ O(nlogn)，和增量序列有关
- 空间：O(1)；**不稳定**
- 评价：只问思路，几乎不手写

### ⑤ 计数排序（非比较排序）

- 思想：统计每个元素出现次数，按次数输出；**要求数据范围不大、整数**
- 时间：O(n+k)，k 是数值范围
- 空间：O(k)；**稳定**
- 限制：不能是负数、数值跨度大时浪费空间

### ⑥ 基数排序（非比较排序）

- 思想：按低位到高位，多轮稳定排序（一般依托计数排序）
- 时间：O(d(n+k))，d 是最大位数
- 稳定；适合整数、字符串，不适合浮点数

### ⑦ 桶排序（非比较排序）

- 思想：划分多个区间桶，元素放入对应桶，桶内各自排序，最后合并
- 理想时间 O(n)；分布不均匀会退化
- 稳定性取决于桶内排序算法

## 六、全部排序对比表

| 排序 | 平均时间 | 最坏 | 空间 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 太慢，仅入门 |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | 小规模/近有序好用 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | 不稳定 |
| 希尔 | ~O(nlogn) | O(n²) | O(1) | ❌ | 很少手写 |
| **快排** | **O(nlogn)** | O(n²) | O(logn) | ❌ | 最快，最常用 |
| **归并** | **O(nlogn)** | O(nlogn) | O(n) | ✅ | 稳定，需额外空间 |
| **堆排** | **O(nlogn)** | O(nlogn) | O(1) | ❌ | 原地，不稳定 |
| 计数 | O(n+k) | O(n+k) | O(k) | ✅ | 限整数小范围 |
| 基数 | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✅ | 整数/字符串 |
| 桶 | O(n) | O(n²) | O(n+k) | 看桶内 | 分布均匀才快 |

## 七、怎么选

| 场景 | 推荐 |
| --- | --- |
| 通用、追求速度 | **快排** |
| 需要稳定 | **归并**（或 TimSort，Python 自带） |
| 内存受限、原地 | **堆排** |
| 数据是整数、范围小 | **计数/基数** |
| 数据接近有序、小规模 | **插入** |

> 实战提醒：**Python 自带的 `sorted()` / `list.sort()` 用的是 TimSort（归并 + 插入的混合），稳定且极快**，生产里直接用，别自己造轮子。手写排序是为了面试和懂原理。
