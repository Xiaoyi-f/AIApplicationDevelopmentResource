## 二、ACM 赛制：3 小时怎么分配

百度之星初赛 3 小时 8 题，ACM 赛制（按 AC 数排名，题数相同比总用时，错误提交罚时 20 分钟）。**策略直接决定成绩**：

| 时间 | 动作 |
| --- | --- |
| **前 10 分钟** | 扫全部 8 题，标记难度，挑最简单的先做 |
| **前 1 小时** | 全力 AC 简单题（签到题），确保「会的不丢分」 |
| **中 1.5 小时** | 攻中等题，卡住就换题，不死磕 |
| **最后 30 分钟** | 收尾、检查、把「半成品」尽量补成能提交 |

**四条铁律**：

1. **先易后难**：先 AC 掉所有送分题，把基础分拿到手；
2. **不卡题**：一道题 20 分钟没思路就换，回头再看；
3. **先写暴力**：不会正解就先暴力，能过小数据也是分；
4. **少罚时**：提交前本地多测几组，别交 WA（一次罚时 20 分钟，等于白做一题）。

> 一句话：**目标是「多 AC」，不是「死磕一道题」。先扫题、先易后难、会的不丢分。**

## 三、Python 过题六步法

用 Python 打比赛，每次做题走这六步：

```
① 读题     → 圈出输入格式、输出格式、数据范围
② 建模     → 这题考什么算法？(图论/DP/贪心/...)
③ 写暴力   → 先写最笨但正确的解法，确认理解题意
④ 套模板   → 换成对应算法的标准模板
⑤ 本地测   → 用样例 + 手造边界数据验证
⑥ 提交     → 确认无误再交，减少罚时
```

> 关键在**第 ③ 步**：先暴力确认「题意理解对了」，再优化。很多人卡题是「题意理解错了」，不是算法不会。

## 四、实战 1：读题示范（真题「电池问题」）

先来一道**真实真题**，练「读题」。这是 2007 年百度之星初赛题：

> **题目大意**：游戏机手柄需要两节电池。工程师玩游戏时，某节电池没电了就拿走、换上一节全新的，还有电的继续用。给定每种电池的使用时长和个数，求**游戏时长的最小值和最大值**。
> 样例：三种电池（3 小时、5 小时、8 小时）。输出最短 5、最长 8。

**读题关键（这题难在读题，不在算法）**：

1. 先圈出**约束**：「一节没电换一节新的，有电的继续用」→ 两节电池**同时消耗**；
2. 圈出**问什么**：单次游戏的**最短**和**最长**时长；
3. 看**样例推规则**：用 3 和 5 开始 → 3 小时后 3 耗尽换 8 → 5 还剩 2 → 2 小时后 5 耗尽、没电池了 → 总 5 小时（最短）。用 8 开始 → 8 小时（最长）。

**建模**：这是一道**贪心**题。直觉是——

- **最长**：尽量让「同时用的两节」都长，避免短电池拖后腿，让长电池充分释放；
- **最短**：反过来，让短电池快速耗尽、长电池「被迫浪费」。

**读题结论**：很多竞赛题的难度在**「读懂规则 + 从样例反推」**，而不是算法本身。这类题务必**手算样例**，确认规则后再动代码。

> 提醒：早期真题题干偶尔有翻译/OCR 瑕疵，正式比赛以官方题面为准。这里重点是**「读题 → 样例反推 → 建模」的方法**，不是背答案。

## 五、实战 2：过河卒（DP，完整过题）

经典 DP 题（NOIP 2002 普及组，难度贴合百度之星初赛）。完整走一遍六步法。

**① 读题**：棋盘 A 点(0,0) 到 B 点(n,m)，卒只能向右或向下走。棋盘上有马（及其控制点），卒不能经过。问**路径数**。

**② 建模**：网格路径计数 → **动态规划**。`dp[i][j]` = 到 (i,j) 的路径数。

**③ 状态转移**：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]   (只能从左边或上边来)
马的控制点 → dp = 0
```

**④⑤ 完整 Python 代码**：

```python
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    n, m = int(data[0]), int(data[1])
    hx, hy = int(data[2]), int(data[3])  # 马的位置

    # 马的控制点 (含马自己)
    blocked = set()
    moves = [(0, 0), (1, 2), (2, 1), (2, -1), (1, -2),
             (-1, -2), (-2, -1), (-2, 1), (-1, 2)]
    for dx, dy in moves:
        x, y = hx + dx, hy + dy
        if 0 <= x <= n and 0 <= y <= m:
            blocked.add((x, y))

    # dp[i][j] 到 (i,j) 的路径数
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = 1
    for i in range(n + 1):
        for j in range(m + 1):
            if (i, j) in blocked or (i == 0 and j == 0):
                continue
            if i > 0:
                dp[i][j] += dp[i - 1][j]
            if j > 0:
                dp[i][j] += dp[i][j - 1]

    sys.stdout.write(str(dp[n][m]) + "\n")

if __name__ == "__main__":
    solve()
```

**⑥ 本地测**：样例 `n=6 m=6 hx=3 hy=3` → 输出 `6`。

> 复盘点：**「只能向右/向下」直接导出转移方程**，这是网格类 DP 的固定套路。马的控制点用 `set` 存，O(1) 判断。

## 六、实战 3：最短路（Dijkstra 完整过题）

图论模板题的实战应用（你在「图论基础」篇学过）。

**① 读题**：n 个点 m 条带权无向边，求 1 号点到 n 号点的最短距离。

**② 建模**：单源最短路 → **Dijkstra**（边权非负）。

**③ 直接套模板**（快读 + 堆优化）：

```python
import sys
import heapq

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n, m = int(next(it)), int(next(it))

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = int(next(it)), int(next(it)), int(next(it))
        g[u].append((v, w))
        g[v].append((u, w))  # 无向图

    INF = float("inf")
    dist = [INF] * (n + 1)
    dist[1] = 0
    pq = [(0, 1)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    sys.stdout.write(str(dist[n]) + "\n")

if __name__ == "__main__":
    solve()
```

> 复盘点：**看到「最短路 + 非负边权」→ 秒 Dijkstra**。模板要熟到「闭眼能写」，比赛时直接敲，省下思考时间。

## 七、实战 4：01 背包（DP 完整过题）

背包是 DP 最高频的模型（你在「背包」篇学过）。

**① 读题**：n 件物品，每件有重量 w 和价值 v，背包容量 V，求最大价值（每件最多选一次）。

**② 建模**：01 背包 → **一维滚动 DP**。

**③ 完整 Python 代码**：

```python
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n, V = int(next(it)), int(next(it))

    dp = [0] * (V + 1)
    for _ in range(n):
        w, v = int(next(it)), int(next(it))
        # 倒序更新, 保证每件物品只用一次
        for j in range(V, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)

    sys.stdout.write(str(dp[V]) + "\n")

if __name__ == "__main__":
    solve()
```

**④⑤ 测试**：`n=4 V=5`，物品 `(2,3)(1,2)(3,4)(2,2)` → 最大价值 `7`。

> 复盘点：**「每件最多选一次」→ 01 背包 → 一维数组 + 倒序遍历**（倒序是防重复用的关键，正序会变成完全背包）。

## 八、赛后复盘

打完比赛，复盘比刷题更重要：

| 步骤 | 做什么 |
| --- | --- |
| **对答案** | 没 AC 的题看题解，搞懂正解 |
| **记模板** | 把比赛里「卡壳」的算法补进自己的模板库 |
| **记陷阱** | 记录「题意理解错」「边界没处理好」的地方 |
| **改时间** | 反思时间分配，下次调整策略 |

> 一句话：**比赛是「暴露问题」，复盘是「解决问题」。只比赛不复盘，等于白打。**
