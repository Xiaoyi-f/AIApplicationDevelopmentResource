## 一、为什么需要它们

回顾一下：

| 需求 | 前缀和 | 差分 | 树状数组/线段树 |
| --- | --- | --- | --- |
| 只查区间和 | ✅ O(1) | ❌ | ✅ |
| 只改区间值 | ❌ | ✅ O(1) | ✅ |
| **边改边查** | ❌ | ❌ | ✅ O(log n) |

**树状数组和线段树专门解决「动态区间」问题**：既要频繁修改元素，又要频繁查询区间和/最值，两者都 O(log n)。

> 一句话：**前缀和/差分是「静态专用」，树状数组/线段树是「动态通用」，支持边改边查。**

## 二、树状数组：单点改 + 前缀和

树状数组（Binary Indexed Tree，BIT）支持**单点修改 + 前缀和查询**，都是 O(log n)。代码极短，是竞赛首选。

```python
class Fenwick:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def lowbit(self, x):
        return x & (-x)

    def update(self, i, delta):
        # 第 i 个位置 (从 1 开始) 加上 delta
        while i <= self.n:
            self.tree[i] += delta
            i += self.lowbit(i)

    def query(self, i):
        # 前 i 个元素的和 (前缀和)
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= self.lowbit(i)
        return s

    def range_sum(self, l, r):
        # 区间 [l, r] 的和
        return self.query(r) - self.query(l - 1)

if __name__ == "__main__":
    fw = Fenwick(5)
    # 初始数组 [0,0,0,0,0], 依次插入
    for i, v in enumerate([1, 3, 5, 7, 9], start=1):
        fw.update(i, v)
    print(fw.query(5))            # 前 5 个和 = 25
    print(fw.range_sum(2, 4))     # 3+5+7 = 15
    fw.update(3, 10)              # 位置 3 加 10
    print(fw.range_sum(2, 4))     # 3+15+7 = 25
```

> 一句话：**树状数组 = update 和 query 都是「顺着 lowbit 往上/往下跳」，O(log n)，代码只要十几行。**

## 三、lowbit 的奥秘

树状数组的灵魂是 `lowbit(x) = x & (-x)`，它取出 x 二进制里**最低位的 1 对应的值**：

```python
def lowbit(x):
    return x & (-x)

print(lowbit(6))   # 6=110, 最低位1代表2 -> 2
print(lowbit(8))   # 8=1000 -> 8
print(lowbit(7))   # 7=111 -> 1
```

**树状数组的结构理解**：`tree[i]` 维护的是「以 i 结尾、长度为 lowbit(i) 的一段」的和。比如：

- `tree[8]` 管 `[1..8]`（lowbit(8)=8）；
- `tree[6]` 管 `[5..6]`（lowbit(6)=2）；
- `tree[7]` 管 `[7..7]`（lowbit(7)=1）。

**update 往上跳**（`i += lowbit(i)`）是为了更新所有「覆盖了 i 的区间」；**query 往下跳**（`i -= lowbit(i)`）是为了累加所有「拼成 [1..i] 的区间」。

> 一句话：**lowbit 是树状数组的密码——update 往上加、query 往下减，都是跳 lowbit。**

## 四、线段树：区间改 + 区间查

线段树更强大，支持**区间修改 + 区间查询**（区间和、区间最值），用「递归 + 分治」实现。核心是**懒标记（lazy tag）**，把区间修改也降到 O(log n)。

```python
class SegTree:
    def __init__(self, arr):
        n = len(arr)
        self.n = n
        self.tree = [0] * (4 * n)      # 开 4 倍空间
        self.lazy = [0] * (4 * n)
        self._build(arr, 1, 0, n - 1)

    def _build(self, arr, node, l, r):
        if l == r:
            self.tree[node] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, node * 2, l, mid)
        self._build(arr, node * 2 + 1, mid + 1, r)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]

    def _push_down(self, node, l, r):
        # 把懒标记下传给子节点
        if self.lazy[node]:
            mid = (l + r) // 2
            self.tree[node * 2] += self.lazy[node] * (mid - l + 1)
            self.tree[node * 2 + 1] += self.lazy[node] * (r - mid)
            self.lazy[node * 2] += self.lazy[node]
            self.lazy[node * 2 + 1] += self.lazy[node]
            self.lazy[node] = 0

    def range_add(self, ql, qr, val, node=1, l=0, r=None):
        if r is None:
            r = self.n - 1
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:      # 完全覆盖
            self.tree[node] += val * (r - l + 1)
            self.lazy[node] += val
            return
        self._push_down(node, l, r)
        mid = (l + r) // 2
        self.range_add(ql, qr, val, node * 2, l, mid)
        self.range_add(ql, qr, val, node * 2 + 1, mid + 1, r)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]

    def range_sum(self, ql, qr, node=1, l=0, r=None):
        if r is None:
            r = self.n - 1
        if ql > r or qr < l:
            return 0
        if ql <= l and r <= qr:
            return self.tree[node]
        self._push_down(node, l, r)
        mid = (l + r) // 2
        return (self.range_sum(ql, qr, node * 2, l, mid)
                + self.range_sum(ql, qr, node * 2 + 1, mid + 1, r))

if __name__ == "__main__":
    seg = SegTree([1, 3, 5, 7, 9])
    print(seg.range_sum(1, 3))   # 3+5+7 = 15
    seg.range_add(1, 3, 2)       # [1..3] 都加 2
    print(seg.range_sum(1, 3))   # 5+7+9 = 21
```

**线段树四要素**：

| 概念 | 说明 |
| --- | --- |
| 树结构 | 每个节点管一段区间，节点 2n/2n+1 是左右儿子 |
| 4 倍空间 | 数组要开 `4 * n` 才够存 |
| 区间分解 | 查询/修改区间被分解成 O(log n) 个节点 |
| **懒标记** | 区间修改先不递归到底，打个标记，需要时再下传 |

> 一句话：**线段树 = 分治 + 懒标记。区间操作被拆成 O(log n) 段，懒标记让「区间改」不必每个元素都改。**

## 五、树状数组 vs 线段树

| 维度 | 树状数组 | 线段树 |
| --- | --- | --- |
| 代码量 | 十几行，简单 | 几十行，复杂 |
| 单点改 + 前缀和 | ✅ 最佳 | ✅ |
| 区间改 + 区间和 | 需差分技巧 | ✅ 直接支持 |
| 区间最值 | ❌ | ✅ |
| 空间 | O(n) | O(4n) |
| 适用 | 求和类 | 通用（和/最值/各种合并） |

> 竞赛直觉：**能树状数组解决就用树状数组（代码短、常数小）；需要区间最值、复杂合并就用线段树。**

## 六、速查表

| 点 | 要点 |
| --- | --- |
| 定位 | 动态区间，边改边查 O(log n) |
| 树状数组 | lowbit 跳，单点改 + 前缀和 |
| lowbit | `x & (-x)`，最低位 1 |
| update | `i += lowbit(i)` 往上 |
| query | `i -= lowbit(i)` 往下 |
| 线段树 | 分治 + 4 倍空间 + 懒标记 |
| 懒标记 | 区间改不递归到底，下传用 |

---

**一句话总结**：树状数组用 lowbit 实现 O(log n) 的单点改 + 前缀和，代码极短；线段树用分治 + 懒标记支持更通用的区间改 + 区间查。前缀和管静态，这俩管动态，一脉相承。
